# Retro TV (Modern Oak Edition)

An Android TV IPTV player styled like a classic wooden CRT television, with modern typography and frosted-glass overlays. Open the app and it starts streaming immediately, like switching on a real TV.

- Package: `com.retro.iptv` · Version 1.2 · minSdk 26 · targetSdk 35
- Stack: Kotlin, Jetpack Compose, AndroidX Media3 (ExoPlayer, HLS)
- No login, no ads, no home-screen clutter

## Design system: "Modern Oak"

Designed for 10-foot viewing: large, high-contrast, readable from across the room.

| Element | Hex | Use |
| :-- | :-- | :-- |
| Dark Oak Base | `#140F0C` | Backgrounds, overlays |
| Oak Surface | `#261A13` | Selected channel, panels |
| Oak Surface Elevated | `#38271D` | Focused item background |
| Amber Dial | `#E07A38` | Focus borders, channel numbers, spinner |
| Parchment White | `#FAF4ED` | Primary text |
| Warm Ash Muted | `#A8988B` | Secondary text |
| Smoky Oak Glass | `rgba(20,15,12,0.82)` | Translucent sidebar over live video |

## UI components

- **CRT exit (`CrtTvExitEffect`)**: pressing Back while watching collapses the picture into a bright horizontal line, snaps it to a center dot, fades the dot to black, then closes the app.
- **Channel sidebar (`ChannelSidebar`)**: slides in from the left at ~35% of the screen width over the live video. The current channel is pre-focused. A focused row gets an amber border and larger text.
- **Channel banner (`ChannelOsdBanner`)**: shows `CH 01` plus the channel title at bottom-left for 3 seconds when you change channels.
- **Loading and errors**: amber spinner while buffering; an error box on playback failure or when the playlist can't be loaded.
- **Settings panel (`SettingsPanel`)**: set the playlist URL or import a local `.m3u` file.

## Remote control

```
              ▲ Volume UP
              │
  Prev CH ◄───┼───► Next CH
              │
              ▼ Volume DOWN

   [ OK ]   ──► Opens the channel sidebar
   [ BACK ] ──► Closes the sidebar/settings if open, otherwise CRT exit
```

| Button | Watching | Sidebar open | Settings open |
| :-- | :-- | :-- | :-- |
| Right / Channel Up | Next channel | Close sidebar | Move in panel |
| Left / Channel Down | Previous channel | Open Settings | Move in panel |
| Up / Down | Volume up / down | Move through list | Move in panel |
| OK | Open sidebar | Play focused channel | Activate button / open keyboard on the URL field |
| Menu | Open Settings | Open Settings | Close Settings |
| Back | CRT exit | Close sidebar | Close Settings |

The sidebar also has a SETTINGS button at the top, for remotes without a Menu key.

## Playlists

- On launch the app loads an M3U/M3U8 playlist from a URL. The default is `https://iptv-org.github.io/iptv/countries/bd.m3u` (`DEFAULT_PLAYLIST_URL` in `MainActivity.kt`).
- The last good playlist is cached on the device and used if the network fails.
- If nothing can be loaded and nothing is cached, three built-in demo channels play.
- The last watched channel is remembered and resumed on the next launch.
- Only `http(s)` stream entries are used. Duplicate URLs are removed.

### Settings panel

| Control | Action |
| :-- | :-- |
| URL field | Press OK to open the on-screen keyboard and type; Done saves |
| Save & Reload | Validate the URL, fetch it, replace the channel list |
| Paste | Paste the URL from the clipboard into the field |
| Import .m3u file | Pick a local playlist file (needs a file picker on the device) |
| Reset | Go back to the default playlist URL |
| Close | Close the panel |

If a file picker isn't available (common on Android TV), use a URL instead.

## Playback and lifecycle

- ExoPlayer plays HLS (`.m3u8`) and MP4. `usesCleartextTraffic` is enabled so `http://` streams work.
- Playback pauses when the app goes to the background and resumes on return, jumping to the live edge for live streams.
- Rendering uses `PlayerView` inside Compose `AndroidView` with hardware acceleration.

## Build

GitHub Actions (`.github/workflows/blank.yml`) builds a debug APK on every push and on manual run. Download `app-debug-apk` from the run's Artifacts.

Locally: JDK 17, then `./gradlew assembleDebug` (output: `app/build/outputs/apk/debug/app-debug.apk`). The wrapper is generated by CI if missing.
